# Qo'l bilan boshqaruv 🖐️

Kamera orqali qo'l harakatlarini kuzatib, ekrandagi kartalarni boshqaradigan interaktiv sayt.

- Ekranda qo'lingiz nusxasi real vaqtda harakatlanadi
- 🤏 Bosh va ko'rsatkich barmoqni chimdib kartani ushlang — karta ushlangan joyida qoladi va qo'lingiz bilan birga buriladi
- 💨 Silkitib qo'yib yuborsangiz karta uchib ketadi
- 🙌 Ikki qo'l bilan ushlab kattalashtiring va bur
- 👋 Qo'lingizni silkiting — sayt salom beradi

Texnologiya: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker), oddiy HTML/CSS/JS (build kerak emas).

## Lokal ishga tushirish

```bash
python3 -m http.server 5173
```

So'ng brauzerda `http://localhost:5173` ni oching va kameraga ruxsat bering.
